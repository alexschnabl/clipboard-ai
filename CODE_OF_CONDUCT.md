# Code of conduct

Be civil. Argue about the code, not the person. No harassment, no slurs, no personal attacks, no posting other people's private information.

This applies to issues, pull requests and everything else in this repository.

If someone crosses that line, the maintainer removes the content and, if it continues, blocks the account. To report something, email the maintainer (the address is on the commits in this repo) or use GitHub's "Report content" on the comment.
